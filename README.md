# 慢光之间 · bradyci.com

阿杰（Brady Ci）的个人网站，记录庭院生活、AI 影像、制冷实践、文字与成长。使用纯 HTML、CSS 和 JavaScript 构建，通过 Cloudflare Workers Static Assets 部署。

## 本地预览

直接打开 `index.html`，或者在本目录启动任意静态文件服务器。

## Cloudflare 发布设置

- 构建命令：留空
- 根目录：仓库根目录
- 部署命令：`npx wrangler deploy`

## 主要内容

- 庭院与植物
- AI 影像实验
- 制冷专业实践
- 文章与成长记录
- 自媒体平台及公开联系方式
